# Living Screensavers

Animerade skärmsläckare för GNOME med nio motiv. Välj motiv med 1–9 eller piltangenterna. F11 växlar helskärm och Esc avslutar.

Bevakningen visar animationen under sista minuten före GNOMEs inställda inaktivitetstid. Vid låsning tar GNOMEs låsskärm över. Automatisk start är aktiv efter nästa inloggning.

Kräver GTK 4, Python, PyGObject, pycairo och GNOME Shell med Mutter IdleMonitor. Bilderna är AI-genererade.
